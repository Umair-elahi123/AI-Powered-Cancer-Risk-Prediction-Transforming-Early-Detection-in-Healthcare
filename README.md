# AI-Powered-Cancer-Risk-Prediction-Transforming-Early-Detection-in-Healthcare
Developed a Cancer Prediction System with 5,000 patient records and 24 features, using Random Forest, XGBoost, LightGBM &amp; Ensembles. The RF + XGBoost Ensemble achieved 90–95% accuracy. An interactive Streamlit dashboard delivers real-time predictions, insights, and global cancer analysis.
